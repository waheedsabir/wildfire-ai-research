# Prospective research roadmap

**Status: planning.** The stages below are targets, not claims of work completed. Calendar dates will be added only when activities actually occur.

| Phase | Proposed task | Verifiable output |
| --- | --- | --- |
| 1 | Select historical incident(s), identify and document suitable public data | Study-area note, source manifest, actual acquisition dates |
| 2 | Explore NASA FIRMS thermal anomaly observations | Reproducible script invocation, data checksums, exploratory counts and limitations |
| 3 | Acquire suitable aerial/satellite image labels for smoke/fire | Annotation guide and train/test split by event |
| 4 | Train and evaluate baseline object detection | Training configuration, logs, precision/recall, false-positive examples |
| 5 | Explore attention-enhanced detection variants | Ablation table, controlled experiments, negative results |
| 6 | Compare historical spread forecasts with simple baselines | Temporal data alignment, accuracy evaluation and uncertainty |
| 7 | Visualize historical spatial risk layers in a research dashboard | Demo, source attribution, non-operational disclaimer |
| 8 | Prepare a technical report and reproducible release | Versioned artifacts, methods, known limitations |

## How completion is recorded
For each completed task, open a dated issue or update `EVIDENCE_LOG.md` with (1) real activity, (2) contributor, (3) source dataset or artifact, (4) code commit/DOI, (5) outcome and limitations.

This repository was created as a prospective research record. New activities will be dated when they occur, not backdated.
